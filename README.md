# retail-profit-analysis
Retail profit analysis project using Python and Power BI
Retail Profit Analysis

This project analyzes retail sales data from a Superstore dataset to understand profitability across categories, sub-categories, and regions. The analysis was done using Python (Pandas, NumPy), and the results were visualized in Power BI.

Project Overview
Objective: Identify which product categories, sub-categories, and regions contribute the most to the store’s profit.
Dataset: Superstore dataset containing columns such as Order ID, Product Category, Sub-Category, Sales, Quantity, Discount, and Profit.
Analysis Steps:
Explore and clean the data.
Analyze profit by Category, Sub-Category, and Region.
Export the aggregated data for visualization in Power BI.

Key Findings
Most profitable category: Technology
Most profitable region: West
Most profitable sub-category: Copiers
The analysis provides insights to guide inventory planning, sales strategy, and resource allocation.

Files in the Repo
